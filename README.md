## What it does

Data Catalog Copilot scans your warehouse, generates table and column documentation, maps lineage end-to-end, and assigns ownership — turning an undocumented swamp into a searchable, trustworthy catalog.

## Key features

- **Auto-documentation** — AI-written table/column descriptions from schemas, queries, and usage.
- **Lineage mapping** — source-to-dashboard lineage parsed from SQL and orchestrators.
- **Ownership suggestions** — inferred from commit and query history.
- **PII classification** — sensitive columns detected and tagged automatically.
- **Slack Q&A** — ask "where is revenue defined?" and get the table, owner, and docs.

## Who it's for

Data teams who know documentation matters but never have time to write it.
